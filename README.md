PÁGINA WEB PERSONAL (HTML, CSS, JAVASCRIPT)



Ver sitio: https://lean-iv.github.io/



Proyecto personal desarrollado con HTML, CSS y JavaScript que funciona como sitio de presentación profesional y portfolio web. La página centraliza información clave del perfil, incluyendo conocimientos técnicos, proyectos y medios de contacto, con el objetivo de ofrecer una visión clara y accesible para reclutadores y entornos laborales.



OBJETIVOS DEL PROYECTO



Simular un sitio web personal que permita:



Presentar información profesional de forma clara y ordenada

Mostrar conocimientos técnicos de manera visual mediante cards

Exponer proyectos relevantes con descripción y acceso a repositorios

Centralizar medios de contacto en un solo lugar

Contar con una presencia online propia utilizando GitHub Pages

Aplicar una estructura simple, mantenible y fácil de navegar



El foco del proyecto está puesto en la presentación del perfil, la organización del contenido y la construcción de una web estática moderna y funcional.



CONCEPTOS APLICADOS



Estructuración de páginas con HTML

Diseño y estilos visuales con CSS

Interactividad con JavaScript

Manipulación del DOM

Uso de modales para mostrar contenido dinámico

Diseño basado en cards para organizar información

Organización de recursos estáticos

Navegación simple orientada a portfolio

Publicación web mediante GitHub Pages



ESTRUCTURA DEL PROYECTO



index.html: contiene la estructura principal del sitio

css/: incluye los estilos visuales (styles.css)

js/: contiene la lógica e interactividad del sitio (script.js)

assets/: almacena recursos como imágenes e íconos utilizados por la web



FUNCIONALIDADES DESTACADAS



Presentación personal y profesional en una sola página

Sección de conocimientos técnicos organizada en cards

Sección de proyectos con descripción y acceso a repositorios

Uso de modales para mostrar contenido sin cambiar de página

Acceso rápido a contacto por WhatsApp, LinkedIn y email

Diseño responsive adaptable a distintos dispositivos

Sitio publicado online mediante GitHub Pages



EJECUCIÓN
